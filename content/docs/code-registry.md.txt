## Status vocabulary

- **authoritative-current**：目前權威核心實作；新的正式研究可以依賴。
- **experiment-frozen**：已完成正式實驗的重現程式；要改語義必須開新 protocol/schema。
- **utility-current**：目前維護中的工程／資料工具。
- **legacy-pilot**：早期或被取代的流程，只供歷史／比較，不得直接作新正式結論。
- **one-time-archive**：一次性 migration / patch 機制，完成後不應保持可觸發狀態。

### Historical / archived workflow policy

Completed V3/V4 one-shot workflows have been removed from the active workflow directory. Their historical commits, frozen source code, formal result directories, experiment-log records and run/artifact identifiers remain the provenance record. Archived copies, where retained under `archive/`, are documentary only and must not be reactivated without a new protocol/version review.

## V4-06 gate rules

- `FORMAL` reruns a deterministic smoke + validator in the same job before development analysis; mere file existence is not accepted as verification.
- Fresh confirmation cannot be enabled by a manual checkbox. It requires `spec/v4_06_frozen_rule.json` plus a matching SHA-256 registered in `spec/project_spec.json`.
- Reserved seeds `202608250101–202608250150` remain blocked until an authoritative validated replay source is generated and wired.
- Formal Actions artifacts are transport copies. Verified evidence must ultimately be committed/archived under `results/v4_06/` with hashes and source provenance before V4-06 can be called verified-complete.

## Maintenance rule

Before using an executable for a new formal experiment:

1. confirm its registry status is `authoritative-current` / `utility-current`, or intentionally fork an `experiment-frozen` runner into a new version;
2. record the runner commit and output schema version;
3. run build/test/validator;
4. do not reuse a `legacy-pilot` or archived workflow merely because it still compiles;
5. if the active workflow set changes, update `spec/project_spec.json` and this registry in the same change series.
