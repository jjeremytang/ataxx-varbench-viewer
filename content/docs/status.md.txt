## Standardization Audit Findings

已確認：

1. Viewer 實作已是 Seed Spec v3，但 public README 仍描述 v2。
2. `PROJECT.md` 曾把 Iterative Deepening 寫成目前 baseline；實際 V3/V4 formal `SearchEngine` 為 fixed-depth Alpha-Beta。
3. V3 locked detector preprocessing / logistic coefficients 被手動複製到 V4 C++ runner，現值未發現不符，但未來有 silent drift 風險。
4. V4-01 per-game summary schema 沒直接保存所有 protocol-level provenance；V4-01 已由 run manifest / derived analysis 補齊，因此不影響既有結論，但 future schema 應升版。
5. `v4-01-patch-decision-logging.yml` 是已完成的一次性 workflow，不應繼續 active。
6. 舊 monolithic V3 dataset workflow 與 authoritative parallel frozen-position pipeline 並存，可能誤導後續重跑。
7. Seed Spec C++ / JS 雙實作缺少共同 fixed-vector regression。
8. Generic Linux CI 原先未在 configure 時指定 `CMAKE_BUILD_TYPE=Release`；formal workflows 本身有指定 Release，因此不影響已完成 V4 timing。
9. `RULES.md` 與目前 core `Game` semantics 未發現版本不一致。

## V4-01 Interpretation Boundary

正式數據支持：

> 在標準 7×7 Ataxx 與 detector 訓練範圍 ply 6–30 內，volatility-aware position-level selective deepening 可提升相較 fixed d4 的棋力，同時使用遠少於 fixed d6 的搜尋成本。

正式數據不支持：PSV-20 已接近 fixed d6、20% 是最佳 budget、d6 是 perfect play、或 detector 可外推到其他 domain。
